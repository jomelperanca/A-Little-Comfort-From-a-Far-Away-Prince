# Moonlit Love 🌙💗

A cute fantasy-themed, BL-inspired comfort website for your boyfriend/partner. It's a static site made with plain HTML, CSS, and JavaScript—no build tools or paid services required.

## Personalize it with your photos
1. Choose 4 photos you both like. For privacy, use photos you're both comfortable sharing online.
2. Put them in the `assets` folder and name them exactly:
   - `us-1.jpg`
   - `us-2.jpg`
   - `us-3.jpg`
   - `us-4.jpg`
3. If your pictures are PNG or WEBP, either convert them to JPG or edit the matching filenames in `index.html` (search for `assets/us-`).
4. Open `index.html` in a browser to test it. Photos are loaded locally from the `assets` folder.

## Put it on GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `moonlit-love` (or another name you like).
2. Upload `index.html`, `README.md`, and the `assets` folder. Keep the folder structure intact.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait a minute or two. GitHub Pages will show the website URL in the Pages section.

## Make it yours
Edit the letter inside `index.html` so it sounds like you. Add your pet names, favorite inside jokes, favorite memories, and a song link if you both want one. Avoid posting private details like addresses, phone numbers, or anything your partner wouldn't want public.

## Run it locally
Double-click `index.html` or open it in a browser. No installation required.
